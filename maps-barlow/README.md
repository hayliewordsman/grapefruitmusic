# Grapefruit Maps: Barlow Edition 1.0

The Google Maps edition of Grapefruit Maps, a separate app from
[Grapefruit Maps Legacy](../maps/README.md), which is unchanged and stays on
OpenStreetMap and F-Droid. **Barlow Edition is not published to F-Droid.**

- Application ID `io.github.hayliewordsman.grapefruitmaps.barlow`, so it
  installs beside Legacy.
- Android **4.2.2 (API 17) and later**, like Legacy.
- Lightweight: no Google Maps SDK, Google Play services or WebView. The app
  talks to Google Maps Platform's web APIs over HTTPS and draws Google's map
  tiles with Legacy's small Mapsforge map view.
- **Offline fallback**: Legacy's downloadable OpenStreetMap country maps.

## Features

- **Google maps**: Map, **Satellite** (with labels) and Terrain views from the
  Map Tiles API. Dark themes use a night-styled Map view. Pan, pinch/zoom,
  location on request and long-press pins. Google's attribution for the
  visible area is shown over the map.
- **Street View**: from the map centre (side button), a dropped pin or the
  Street View tab. Uses the Street View Static API: one light image at a time.
  Turn with the side buttons or by dragging, and look up and down. The nearest
  outdoor panorama within 80 m is found first, at no image charge.
- **Search** with the Geocoding API. Coordinates work without a request.
- **Driving directions** with the Routes API (traffic-aware): distance, time,
  route line and written steps. The last route is saved on the device.
  **Navigate in Google Maps** hands the trip to the Google Maps app or website
  for turn-by-turn guidance.
- **Landscape**: the tab bar becomes a rail of drawn icons on the left. Page
  headers are compact (one slim row on the map). Map and Street View controls
  are round, drawn icon buttons on the sides.
- The same four Grapefruit themes and universal theme support as Legacy,
  including Victory Blue and its About-page game.
- Gulf of Mexico and Lake Ontario: Grapefruit's own labels over the map and in
  search results. Text inside Google's imagery is controlled by Google.

## Offline fallback: OpenStreetMap country maps

Google's terms don't allow downloading or prefetching its map tiles. Google
tiles are cached for one day only, within bounded space. For offline use,
Barlow Edition keeps Legacy's **418 downloadable OpenStreetMap maps under 200
country/territory groups** (Settings › Offline maps), with the same resumable,
validated downloads.

- **Offline mode** (Settings) always shows your downloaded map. Opening a
  downloaded map turns Offline mode on.
- With no connection, or when Google can't be reached or isn't configured, the
  Map tab falls back to a downloaded map automatically.
- Offline, coordinate search, pins and the saved route still work. Street View,
  place search and new directions need a connection.
- Offline maps are © OpenStreetMap contributors (ODbL), downloaded unmodified
  from Mapsforge and rendered on the device.

## Google Maps Platform key

The key is never committed. Supply it at build time as `MAPS_API_KEY`: an
environment variable, a Gradle property, or a line in the ignored root
`local.properties`. Builds without a key work, but they show a "Google Maps
isn't set up" panel.

In Google Cloud, enable **Map Tiles API**, **Street View Static API**,
**Geocoding API** and **Routes API** for the key. Restrict the key to these
APIs. Tile and Street View image requests can't carry Android app headers, so
an Android-app restriction would block them. The app sends `X-Android-Package`
and `X-Android-Cert` on the calls that do support them. Set quotas or budget
alerts: these APIs are billed beyond Google's free usage.

## Build

Use JDK 21 and Android SDK platform 36:

The tests use Mapsforge's Andorra map as a fixture:

```sh
mkdir -p work/maps-beta
curl --fail --location https://download.mapsforge.org/maps/v5/europe/andorra.map -o work/maps-beta/andorra.map
MAPS_API_KEY=… ./gradlew :maps-barlow:assembleRelease :maps-barlow:testReleaseUnitTest :maps-barlow:lintRelease
```

APK: `maps-barlow/build/outputs/apk/release/`. With `GRAPEFRUIT_KEYSTORE` and
`GRAPEFRUIT_KEYSTORE_PASSWORD`, it's signed with the permanent Grapefruit
certificate. The tests cover all pages with and without a key, country downloads (resume,
validation, failures), the offline fallback and offline rendering, the landscape
rail and compact headers, Routes and polyline parsing, Street View request
limits, place names, themes and the Victory Blue game. Screenshots of every
page in both orientations go to `build/reports/maps-preview/`.

`.github/workflows/maps-barlow.yml` builds, tests and lints Barlow Edition
separately. It publishes GitHub releases tagged `maps-barlow-v<version>` from
the default branch. It never touches the F-Droid repository.

The wordmark font subset is generated by `tools/maps-barlow/wordmark.py`.
