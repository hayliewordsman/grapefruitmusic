Grapefruit Maps beta 1.1 fixes the launcher icon accidentally copied from Grapefruit Audio in beta 1.

The new, original icon shows a folded map with a grapefruit location pin. It includes PNG icons for Android 4.2.2 onward and adaptive layers for Android 8 and later. The editable SVG artwork and generator are included in the GPL-3.0-or-later source.

This APK uses the same application ID and Grapefruit signing certificate as beta 1, with versionCode 2, so it installs as an update and keeps your maps and settings.

All beta 1 map features, four themes, naming rules and the Victory Blue Easter egg are retained.
