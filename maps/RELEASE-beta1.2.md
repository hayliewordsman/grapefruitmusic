Grapefruit Maps beta 1.2 puts the back button and heading on one row in Settings subpages.

About, Licenses and the Victory Blue Easter egg now have a compact, round back icon in the top-left corner with the title beside it. The back button has a 48dp touch target and an accessibility label; subtitles sit below the title.

This APK installs over earlier Maps betas with the same app ID and signing certificate, keeping downloaded maps and settings. Android 4.2.2 support is retained.
