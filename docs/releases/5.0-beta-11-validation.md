# Grapefruit Music & Podcasts 5.0 beta 11 — build 60

- Lyrics prefetch: Player.load calls LyricsRepository.prefetch for each new item. For a song (not a
  station or a podcast episode), 3 seconds later, if it's still the one playing, LyricsRepository.load
  runs on a single low-priority thread (gf-lyrics, THREAD_PRIORITY_BACKGROUND): the saved copy, a .lrc
  file beside the song, the server, then LRCLIB (if Find Lyrics Online is on). It is the same lookup as
  opening Lyrics, so whatever it finds (or that there are none, retried after a week) is saved in the
  lyrics table and works offline; a song already looked up costs one database read. Offline lookups
  save nothing, so they're tried again later.
- LyricsRepository.load is serialised per song (16 striped locks): opening Lyrics while the prefetch
  for the same song is running waits for it and then reads the saved copy, instead of asking twice.
- DiscoveryPolicy.EXPLANATION ends "…do not necessarily reflect the views of MagicFlute LLC or
  Grapefruit." (was "…or Grapefruit Music developers.").
- Settings' Find Lyrics Online footer and the README say when lyrics are looked up.
- Radio (Internet Radio with My Stations not scrolling, a row cut short above the bars): could not be
  reproduced (a touch drag scrolls the page on Android 5.0 and 14 in Robolectric) and is fine on the
  device again; it was probably the moment the connection dropped. No change.
