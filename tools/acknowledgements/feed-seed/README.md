Public evidence seeds for the independently refreshed Victory Roll Call feed. Sources are public election pages, term datasets and public self-identification records. The identity directory is reduced to the fields needed for exact name/state/office matching; contact details, photos and unused fields are omitted. Short self-identification excerpts are source-backed by ../identity-evidence.json. Identity evidence was reviewed November 5, 2026; an identity record never supplies evidence of an election win. Raw music and app signing material are never used here.
