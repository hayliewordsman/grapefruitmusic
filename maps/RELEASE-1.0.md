Grapefruit Maps Legacy 1.0 is the first stable release, following beta 2.

The app keeps its package ID and permanent signing certificate, so this release updates existing Grapefruit Maps betas in place and preserves maps, routes and preferences.

- Android 4.2.2 and later, with a lightweight native Grapefruit UI.
- 2D OpenStreetMap and NASA Blue Marble satellite composite views.
- 418 downloadable maps grouped by 200 countries and territories, resumable downloads and local rendering.
- Driving directions, route overview, place search and optional location. Turn-by-turn navigation is not included.
- Four local and universal Grapefruit themes, drawn back/dropdown icons and a centered Geist Pixel Triangle wordmark.
- Victory Blue's optional Victory Break minigame, with bundled artwork and mouth-origin animation.

NASA satellite imagery provides regional detail, up to zoom 8. New directions and place searches require a connection; downloaded 2D maps and the last saved route remain available offline.

GPL-3.0-or-later. Credits, dependency licenses, editable artwork and build recipes are included in source. The stable release is distributed through GitHub Releases and the signed Grapefruit F-Droid repository. Official f-droid.org inclusion is a separate upstream review process.
