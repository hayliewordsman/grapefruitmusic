# Grapefruit Music & Podcasts 5.1 — build 64

5.1 is 5.1 beta 1 and beta 2 (see their validation notes) plus the mini player's scrolling title, on
the repository as it now is, with Grapefruit FAST beside the music app.

## Mini player title

- Reported: a long title in the mini player moved a letter and jumped back to the start. Its
  TextView marquee starts over (stopMarquee in makeNewLayout) whenever the line is measured again
  at a new width, and on Android 4 phones the marquee itself swaps its "…" layout for the scrolling
  one and asks for a new layout as it starts (MARQUEE_FADE_SWITCH_SHOW_ELLIPSIS), so a layout pass
  near the start sends it back to the first letter.
- The mini player's title is now MarqueeText (ui/widget), which draws its own line: a 1.2 s pause,
  then the whole line passes at 30 dp/s (Android's marquee timings), followed by its start after a
  gap of a third of the width; three rounds a song, then it rests at the start. Only a new text, a
  new width, setScrolls or becoming visible start it over; layout passes don't. It moves at about
  30 frames a second (as Android 4.2's marquee) and stops drawing when it rests or Now Playing
  covers it. Fading edges, size (15sp), Geist SemiBold and line height as the TextView had.
- Checked with a temporary Robolectric test (not committed): 17.6 s of frames with a layout request
  every 0.3 s and a player update every 0.5 s: the offset rose steadily at 60 px/s (xhdpi), with no
  jump back; a new song starts over, covered it rests at the start, and a short title never moves.

## Grapefruit FAST in the same repository

- Codex added Grapefruit FAST (`fast/`, its own app ID, key, workflow and `fast-v…` releases) and moved
  Geist, Fonts, Tls and the bundled root certificates into a shared `grapefruit-ui` library. Merged
  here by fast-forward from `codex/grapefruit-fast-1.0-beta-1` (CI green on its branch).
- The music app built from the merged tree (before this release's changes) has the same 82 files as
  the v5.1-beta-2 APK; only classes.dex differs, by the shared library's R class for the bundled
  certificates. `:fast` also builds and passes lint. The music workflows build only `:app`, and the
  F-Droid repository takes only `v…` releases.

## Release

- The APK is now `grapefruit-<version>.apk` (`grapefruit-music-<version>.apk` up to 5.1 beta 2):
  `.github/workflows/fdroid-repo.yml` and the README; the F-Droid recipe's `Binaries:` moves with its
  build to 5.1.
- Version 5.1 (64): a stable release, published to the F-Droid repository.
- Local Gradle (JDK 21): :app:assembleDebug, :app:assembleRelease, :app:testDebugUnitTest, :app:lintDebug.
