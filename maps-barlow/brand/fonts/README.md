Geist Pixel Triangle by Vercel, SIL Open Font License 1.1.

This is the static Triangle WOFF2 from the public `geist` npm package version
1.9.0 (`package/dist/fonts/geist-pixel/GeistPixel-Triangle.woff2`). It provides
the Barlow Edition name's additional glyphs. The full license is bundled in the APK
as `assets/fonts/Geist-OFL.txt` from grapefruit-ui.

`tools/maps-barlow/wordmark.py` uses fontTools and Brotli to create the static TTF
subset for Android 4.2.2 and the outlined SVG masters. Ordinary app builds use
the committed TTF and do not download fonts.
