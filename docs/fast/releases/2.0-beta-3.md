# Grapefruit TV 2.0 beta 3

- Fixed: a long press in an empty field (to paste a playlist address, for example) closed the app on Android 4.x. On Android 4.x, dialog fields no longer open the system's paste pop-up; address, server and username fields have their own Paste button instead, on every Android version.
- Crash reports, as in Music: if Grapefruit TV ever closes unexpectedly, it keeps a short report (app and Android versions, device model, where it stopped; logins and addresses left out) and offers to share it next time. Nothing is sent unless you share it.
- Signed with the permanent Grapefruit key; installs over beta 2.
