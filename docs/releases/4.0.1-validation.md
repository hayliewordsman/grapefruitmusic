# Grapefruit Music 4.0.1 (38)

Base: published v4.0 commit ffec8c6b6597c012d99ce9edf2cb0473d65cba82.

- Scrubber freezes its duration during a gesture, clamps its value when duration changes, follows the original pointer, and cancels without seeking. Now Playing restores time labels after cancellation and disables seeking for unknown duration.
- MediaPlayer serializes asynchronous seeks, coalesces queued targets, and reports the latest requested position until completion. This also prevents podcast resume from briefly showing the old position.
- Podcast reload saves progress before reading its resume position. Seek requests are bounded before converting to Android's integer milliseconds.
- Version 4.0.1, code 38. Package ID, minSdk 17, dependencies, signing configuration and release workflows unchanged.

- 144 unit tests, zero failures/errors. Five new regression tests cover resumed progress, rapid seeking, zero targets, duplicate targets and new targets during a queued seek.
- Android lint passed. No physical device or emulator was attached; touch gestures and network podcast playback have not been verified on hardware in this session.
