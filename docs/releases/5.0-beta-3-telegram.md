🍊 Grapefruit Music & Podcasts 5.0 beta 3

• One app icon for every theme: the grapefruit from the splash screen, round. Grapefruit now has a single launcher entry, so changing the theme no longer changes the icon or moves it. (Updating to this beta may take Grapefruit off your home screen one last time; add it back from the app list.)
• The mini player and the tabs float over the page, on every Android version: pages scroll out from under them, and the last row stops just above them.
• Settings rows and Now Playing's buttons (Lyrics, Karaoke, Live, Up Next) are fully round, like the rest of the new look.

Beta: GitHub prerelease only, not in the F-Droid repository.
