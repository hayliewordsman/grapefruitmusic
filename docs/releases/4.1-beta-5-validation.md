# Grapefruit Music 4.1 beta 5 — build 43

## Live Mode: the ovation waits for the singer

Reported on beta 4: on "Blank Space" the ovation started too early. The band drops out before the
last line is sung, and the mix being 9dB under its recent peak (or falling) in the last 15 seconds
counted as the end. `LiveStage` now also follows the lead vocal (the separator's estimate, or the
centre-band stand-in without it) at the stadium's rate: fast loudness (0.15 s) and a recent peak
falling 0.25dB a second. Neither end condition counts while the vocal is within 10dB of that peak.
A fade-out still starts the ovation once the voice has faded with it; the end of the file still
always does.

New tests: `theOvationWaitsForTheLastWords` (band stops 8 s from the end, the voice 3 s from the
end: ovation between 37 and 38.5 s; beta 4's logic started it at 33.5 s, checked by running the test
against it) and `aFadeOutWithTheSingerFadingToo` (31 to 34 s).

## Now Playing: long text scrolls

The title, album and artist lines (and the small title and artist above the lyrics and Up Next)
use a marquee with faded edges instead of "…", selected in code so Android scrolls them. Short text
doesn't move. The radio and station lines, which already scrolled, keep doing so.
