# Grapefruit Music & Podcasts 5.0 beta 9 — build 58

- Grapefruit Light: grapefruit_light_background is now Settings' grouped peach (#FCE4D9, was
  #FFF3EC), so every page, the splash and the floating bars' fade match Settings; the scrim follows.
- Starlight retired: Settings › Theme offers Grapefruit Light, Grapefruit Dark and Pitch Black.
  A saved Starlight (Prefs.THEME_STARLIGHT) shows as Grapefruit Light (Ui.theme). The light base
  style stays, as Grapefruit Light's parent; the unused Splash.Light styles are removed. README and
  the store description ("Three themes") updated.
- Pitch Black: background and grouped background stay #000000. The rest takes the grapefruit's
  colours: coral accent (#FF7F6B to #F2546B, as Grapefruit Dark), cream text (#FFF3EE), warm grey-
  pink secondary text, and red-tinted near-black surfaces, controls, separators, outlines and
  toggles.
- Karaoke Mode / Live Mode on older hardware: no audio code changed since 4.1.2 (DspEngine, Dsp,
  VocalRemover, LiveCrowd and LiveStage are identical; Player only turns both off for podcasts),
  and Karaoke Mode does the same work whatever the load, so a busy CPU shows as stutter, not as
  weaker vocal removal. The 5.0 look asks more of the CPU while music plays, so:
  - Long titles (mini player, Now Playing) scroll three times per song instead of forever, and
    only where they show: the mini player's title rests while Now Playing covers it, Now
    Playing's while it's closed. A scrolling line redraws every frame, and since 5.0 the mini
    player floats over the page, so each frame also redrew what's under (or over) it.
  - Now Playing's artwork shadow is a cached alpha mask (ALPHA_8, made again only when the size
    or corners change) drawn in the shadow's colour, instead of a software layer that redrew the
    artwork and its blur on the CPU.
  Not measured on the JP5S itself; to be confirmed on the device.
- Rendered with a temporary Robolectric test (not committed): Library, Now Playing, Podcasts,
  Settings and Equalizer in Grapefruit Light, Pitch Black, Grapefruit Dark and with a saved
  Starlight; checked that the mini player's title stops scrolling while Now Playing is open and
  starts again when it closes.
- Version 5.0-beta-9 (58): a prerelease, not published to the F-Droid repository.
- Local Gradle (JDK 21): assembleDebug, assembleRelease, testDebugUnitTest, lintDebug.
