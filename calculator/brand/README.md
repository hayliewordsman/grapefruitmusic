# Grapefruit Calculator icon

`icon.png` is this app’s original launcher artwork: a calculator in the
Grapefruit coral, cream and plum palette, with a citrus slice and teardrop plate.
It replaces the reused Audio/headphones asset. Transparent master artwork was
created with image generation, using the repository’s Grapefruit colors as reference.

Run `calculator/tools/export-icons.sh` from the repository root to export the
five PNG densities. Requires ImageMagick’s `convert`. Android 4.2.2–4.4.4
loads these bitmap icons directly.
