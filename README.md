# Grapefruit Launcher preview download

`Grapefruit-Launcher-1.0-preview.apk` is a debug-signed testing build for Android 4.2.2 (API 17) and later.

Source code: https://github.com/hayliewordsman/grapefruitmusic/tree/codex/grapefruit-launcher-preview

The source branch includes the launcher module, shared Geist fonts, build workflow, tests and installation guide. SHA-256 is in `SHA256SUMS.txt`.
