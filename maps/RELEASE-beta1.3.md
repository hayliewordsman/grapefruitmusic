Grapefruit Maps beta 1.3 adds a custom Geist Pixel Triangle wordmark to About in the same spacious, centered branding layout as the media apps.

About keeps a compact back icon and About heading on the navigation row. Below it, the 88dp Maps icon, large wordmark and version are centered above the settings sections. The Maps-specific wordmark uses a bundled static TTF subset, so it works on Android 4.2.2 without installed fonts or a network connection. Grapefruit takes the selected theme's accent and Maps uses its text color. Outlined SVG masters for all four themes are included in source.

Geist Pixel is by Vercel under SIL Open Font License 1.1. The font subset generator is tools/maps/wordmark.py; the font license is bundled with the app.

This update keeps the Maps icon, compact Settings headers, maps, preferences and Easter egg. It installs over earlier Maps betas using the same application ID and certificate.
